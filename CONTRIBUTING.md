# Cómo colaborar con Brújula Bursátil

Para informar un error, describí el instrumento, la moneda y la vista donde aparece la diferencia, usando cantidades ficticias. Agregá los pasos mínimos para reproducirlo y el resultado que esperabas. Para proponer una mejora, contá qué tarea querés resolver y cómo la harías hoy.

Antes de enviar un cambio, seguí la [guía de uso](GUIA_DE_USO.md) y probá el recorrido que modificaste. En el pull request explicá qué cambió y con qué datos o entorno lo verificaste.
