# Guía de brujula-bursatil

Los componentes de cartera y preferencias están en `src`. Las consultas a proveedores y sus respuestas alternativas están en `worker`. Conservá la lectura de carteras ya guardadas en el navegador.

Corré `pnpm test`, `pnpm run build` y `pnpm run test:e2e`. Para comprobar la API local junto con la interfaz compilada, iniciá `pnpm run preview`.

Consultá los pasos de publicación en [el flujo de GitHub Actions](.github/workflows/deploy.yml).
